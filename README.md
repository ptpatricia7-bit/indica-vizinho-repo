# Indica Vizinho

Site em React + Vite + TypeScript + Tailwind (exportado do Readdy).

## Rodar localmente

```bash
npm install
cp .env.example .env   # preencha com suas chaves do Supabase
npm run dev
```

## Scripts

- `npm run dev` – servidor de desenvolvimento (porta 3000)
- `npm run build` – build de produção (pasta `out`)
- `npm run lint` – ESLint
- `npm run type-check` – checagem TypeScript
